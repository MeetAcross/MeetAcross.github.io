📚 Help & Tutorial

🚀 Quick Start

  1. Add Attendees: Enter name and select timezone for each participant
  2. Select Date: Choose your meeting date and duration
  3. Generate Timeline: Click to visualize time zones
  4. Review Recommendations: Check the best meeting times
  5. Schedule: Create calendar event or download ICS file

🎨 Color Guide

Green: Optimal working hours (9 AM - 5 PM)
Blue: Lunch time (12 PM - 1 PM)
Yellow: Early/Late hours (8-9 AM, 5-7 PM)
Red: Night hours (avoid)
Gray: Weekend
Purple: Best meeting window

💡 Pro Tips

  • Use templates to save frequently used teams
  • Export to CSV for sharing with stakeholders
  • Hover over time slots to see detailed local times
  • Use keyboard shortcuts for faster navigation
  • Enable dark mode for comfortable night viewing
  • Check meeting history to review past meetings

🔌 Platform Integration

  • Use demo mode to test without OAuth
